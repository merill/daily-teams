Settings Policies Reference

7 November 2026Doc update+15 / −15 lines

In brief

The reference now uses broader labels such as “Events up to 1k attendees” and “Events optimized for a large audience” instead of webinar and town hall terminology across related settings.

What Teams admins need to know

Administrators should use the updated policy names when consulting the reference. No administrator action is required.

Summaries are generated from the documentation change itself.
