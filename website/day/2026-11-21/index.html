Day in brief

Teams VDI guidance flags possible BSODs on unsupported Windows Server 2019

The most consequential updates tighten Teams VDI and Teams Phone guidance: Windows Server 2019 VMs may encounter BSODs with Teams 26288.x.x.x or later, while personal voicemail AI triage licensing is now stated per voicemail receiver. Other meaningful changes define Loop meeting-note limits for on-premises Exchange mailboxes, document a Teams Rooms Android Settings failure, and add evaluation and Teams Queues availability detail for voicemail triage. Most remaining edits refresh certified-hardware tables, comparison data, or page structure.

  • Clients · Planning and deployment
    Windows Server 2019 VDI now carries a documented BSOD risk

    The VDI requirements guidance reports possible BSODs on Windows Server 2019 virtual machines running Teams 26288.x.x.x or later. Teams 26276.x.x.x is identified as unaffected; Windows Server 2019 is unsupported, and customers must migrate to Windows Server 2025.

  • Teams Phone · AI and Copilot
    Personal voicemail AI triage licensing is specified per receiver

    The billing guidance now requires a Microsoft 365 Copilot license for each voicemail receiver rather than each user. Administrators should check prerequisite coverage using the receiver as the licensing unit.

  • Teams · General
    Loop meeting notes have a defined on-premises Exchange limitation

    The Exchange and Teams guidance says users with mailboxes hosted on Exchange on-premises can use Loop-based meeting notes for single-instance meetings. Recurring meeting notes aren't supported.

  • Devices · Troubleshooting
    A Teams Rooms Android language change can make Settings unresponsive

    The known-issues guidance identifies version 1449/1.0.96.2026344105: changing the device language may make the Settings menu unresponsive. Restarting the affected device restores access to Settings.

  • Teams Phone · AI and Copilot
    Voicemail AI triage guidance adds evaluation and Queues timing

    The overview now says a compliant evaluation model assesses generated triage insights and monitors triage. It also says shared-voicemail AI triage data will be available in the Teams Queues app soon, while Teams Premium remains required.
