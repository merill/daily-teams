Aa Cq Reference Limits Supported Configurations

6 November 2026Doc update+9 / −11 lines

In brief

The reference table now lists several language locales in a different order, including Indonesian/Icelandic, Lithuanian/Latvian, and the Serbian-to-Spanish entries. The Spanish (Spain) audio link remains associated with es-ES.

What Teams admins need to know

No administrator action is required; consult the updated table order when using the reference page.
