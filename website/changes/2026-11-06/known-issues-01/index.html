Known Issues

6 November 2026Doc update+2 / −1 lines

In brief

The known-issues page now states that Large Gallery might be unavailable as a layout option on Teams Rooms for Android running app versions 1449/1.0.96.2026249711 through 1449/1.0.96.2026264504. The issue is expected to be addressed in a future update.

What Teams admins need to know

Administrators should expect Large Gallery to be unavailable on affected app versions; no action is specified.
