Set Up Events

7 November 2026Doc update+11 / −11 lines

In brief

The setup guide now uses capability-based labels such as “Events up to 1k attendees” and “Events optimized for a large audience” throughout its policy tables and instructions. The associated policy names and commands remain the same.

What Teams admins need to know

Use the updated labels when configuring or documenting event policies. No administrator action is required.
