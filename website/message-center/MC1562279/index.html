Microsoft Teams: View files and conversations side by side

20 November 2026MC1562279 on mc.merill.net ↗Message

In brief

Microsoft Teams will enable side-by-side viewing of files (PDF, Markdown, HTML) and their related conversations, enhancing context during review. This feature will roll out worldwide from late December 2026 to early January 2027 on Windows, Mac, and web, requiring no admin action.

Message Center announcement

What and Why:

Microsoft Teams is introducing a side-by-side experience that helps users review shared files without losing conversation context. When users open a PDF, Markdown, or HTML file from a chat or channel message, the conversation appears alongside the file at the message where it was shared.

This update will be available in Microsoft Teams on Windows, Mac, and the web.

Rollout Schedule:

General Availability (Worldwide, GCC, GCC High, DoD): We will begin rolling out in late December 2026 and expect to complete by early January 2027.

Impact on Your Organization:

When users open a supported file from a chat or channel message, a conversation pane opens alongside the file preview. Users can read the related discussion and send messages or replies without leaving the file preview. Files opened from a file list without an originating message will not show the conversation pane.

Action Required/Recommendations:

No admin action is required. Consider notifying help desk staff and end users, and update internal guidance to explain how users can review files and respond to related conversations side by side.

Compliance considerations:

No compliance considerations identified. Review as appropriate for your organization.
