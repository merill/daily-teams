Microsoft Teams for Android and iOS: Update to the latest app version to maintain file access

24 November 2026MC1567258 on mc.merill.net ↗Major update

In brief

Update Microsoft Teams mobile to version 1416/1.0.0.2026151302 (Android) or 8.19.0 (iOS) by April 1, 2027, to maintain file access. Older versions will lose file functionality due to a shift to Microsoft Entra ID authentication replacing pre-authenticated URLs. Begin updates now.

Message Center announcement

What and why

We are updating how Microsoft Teams mobile authenticates access to files stored in SharePoint Online and OneDrive. To improve security, we are retiring pre-authenticated URLs and transitioning file access to Microsoft Entra ID-based authentication.

To support this change, users must run a compatible version of Teams for Android (1416/1.0.0.2026151302 or later) or iOS (8.19.0 or later). Users running older, incompatible versions may experience failures in affected file scenarios after enforcement begins on April 1, 2027. We recommend that you begin preparing now to ensure users are running compatible Teams mobile versions before enforcement begins.

Rollout schedule

  • General Availability (Worldwide, GCC, GCC High, DoD): Rollout will begin in mid-March 2027 and is expected to complete by early April 2027.

Impact on your organization

Who is affected

  • Users running older, incompatible versions of Microsoft Teams for Android or iOS.

Platforms and services

  • Microsoft Teams for Android
  • Microsoft Teams for iOS

What will happen

  • Beginning April 1, 2027, users running older, incompatible versions may experience failures when: 
    • Opening files shared in Teams.
    • Previewing files and thumbnails in chats and channels.
    • Downloading files from Teams.
    • Uploading and sharing files from their devices.
    • Playing videos stored in OneDrive or SharePoint within Teams.
    • Sharing slides in meetings using PowerPoint Live.
    • Sharing files with bots and agents.
  • Users running compatible Teams mobile versions will continue to access files through the affected scenarios as expected.
  • Other Teams functionality will not be affected by this change.

Action required and recommendations

To prepare for enforcement on April 1, 2027, we recommend that you begin updating users now and complete the following actions before that date:

  • Encourage users to update Microsoft Teams mobile to the latest available version.
  • Ensure Android users are running Teams version 1416/1.0.0.2026151302 or later.
  • Ensure iOS users are running Teams version 8.19.0 or later.
  • Review your mobile app management and deployment policies, where applicable, to help ensure users receive an updated Teams version.
  • Communicate the update requirement to users running older, incompatible versions.
  • Update internal help desk guidance and documentation as appropriate.

No action is required for users already running the minimum compatible version or later.

Important: Disabling pre-authenticated URLs (tempauth) through PowerShell before April 1, 2027, may disrupt file scenarios across Teams mobile, regardless of app version. We recommend avoiding this change until the scheduled enforcement date.
