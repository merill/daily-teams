Microsoft Teams: New chat sections for muted and meeting chats

New

Microsoft Teams will introduce two new chat sections—Muted chats (enabled by default) and Meeting chats (disabled by default)—to organize conversations. Rollout begins January 2027. Users can enable/disable and reorder these sections; no admin action is needed. Muted chats move automatically to their section unless favorited.

Microsoft Teams: Automatically add tag members to channels with Workflows

New

Microsoft Teams will introduce a Workflows app template to automatically add users to channels when they are added to a team tag. This optional feature, rolling out worldwide in mid-December 2026, helps streamline access for location- or project-based groups without default changes.

5 November 2026

Microsoft Teams: Decline incoming mobile calls with a message

New

Microsoft Teams mobile users will soon be able to decline incoming calls with a predefined or custom message sent via Teams chat. This feature, rolling out worldwide in December 2026, enhances communication without answering calls. It applies only to Teams-to-Teams calls with available chat and requires no admin action.
