Manage Registration Form Events

7 November 2026Doc update+3 / −3 lines

In brief

The documentation now refers to the setting as **Events registration form questions** instead of **Webinar registration form questions**. The page metadata was also updated.

What Teams admins need to know

Administrators should use the updated setting name when following the documented configuration steps; no action is required unless updating internal guidance.
