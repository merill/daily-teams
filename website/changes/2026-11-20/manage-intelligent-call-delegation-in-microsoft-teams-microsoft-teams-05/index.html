APPLIES TO:Meetings Events Calls

Intelligent call delegation in Microsoft Teams is an AI-powered voice agent that helps users manage incoming calls. It answers calls on users' behalf, gathers context about the caller's intent, and takes action based on users' availability and settings. It can screen calls, route urgent calls to users, and schedule follow-up appointments through Microsoft Bookings.

As an admin, you use Teams personal attendantintelligent call delegation policies to control whether users in your organization can use intelligentIntelligent call delegation, and which settings are available to them.

Prerequisites

  • Users must have a Microsoft Copilot license.

  • Intelligent call delegation uses usage-based billing with Copilot Credits. Admins must set up usage-based billing for Copilot Credits and create a spending policy for intelligentIntelligent call delegation in the Microsoft 365 admin center.

    Note

    When you create the spending policy, under Agents and services, ensure that only Intelligent call delegation is selected. Clear the checkboxes for all other services. When you select users and groups, choose the appropriate scope before assigning the policy.

How intelligentIntelligent call delegation works

When users turn on intelligentIntelligent call delegation, the voice agent answers calls on their behalf. Depending on the user's settings, it can perform actions including:

  • Screen incoming calls and collect the caller's reason for calling.
  • Route urgent calls to the user and provide context about the call.
  • Notify the user when it answers or takes action on a call. Users can monitor calls through a live preview and join at any time.
  • Provide a post-call summary in call history when available.

Callers are informed that they're speaking with an attendant rather than a person. When intelligentIntelligent call delegation is turned on, it replaces the user's existing call routing settings. For more information about the user experience, see Use Intelligent call delegation in Microsoft Teams.

Manage intelligentIntelligent call delegation

You can use the Teams admin center or PowerShell to manage intelligentIntelligent call delegation for your users. By default, intelligentIntelligent call delegation is enabled in Teams personal attendantthe policy, and users with the policy can choose whether to turn it on or off in their Teams settings. Individual settings, such as call screening and scheduling follow-ups, are also enabled by default, and users can change them. Depending on the setting, users can turn it on or off or choose from available options.

Use the Teams admin center

  1. In the left navigation of the Teams admin center, go to Voice > Personal attendantIntelligent call delegation policies.

  2. Select an existing policy or create a new one.

  3. Under General, turn Enable Personal AttendantIntelligent call delegation on or off.

  4. If you turned on Enable Personal AttendantIntelligent call delegation, configure the remaining policy settings under the following sections:

    • Choose how Personal AttendantIntelligent call delegation speaks
    • Choose which calls Personal AttendantIntelligent call delegation answers
    • Choose what Personal AttendantIntelligent call delegation can do
    • Manage recording and transcription

    For more information about each policy setting, see the Policy settings table.
