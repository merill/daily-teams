This article is for IT pros and administrators who want to delegate auto attendant and call queue change capabilities to users in their organization.

As an administrator, you create and assign voice applications policies to authorized users. Voice applications policies control what configuration changes an authorized user can make to the auto attendants and call queuesvoice applications they're authorized for.

Before creating and assigning policies, read Plan for authorized users for licensing information and Set up authorized users. Some configuration capabilities require a Teams Premium license.

The global, org-wide default policy disables all configuration change capabilities for all users. This policy shouldn't be changed.

You must create and assign custom policies to allow authorized users to make configuration changes to auto attendants and call queues.voice applications.

Best practice: The custom policy assigned to a user should provide the minimum levels of permissions the user needs to perform their job.

Create a custom voice applications policy

Create custom policies that reflect the configuration changes you want to allow authorized users to make to auto attendants and call queues.voice applications.

  1. In the left navigation of the Teams admin center, go to Voice > Voice applications policies.
  2. Select Add.

To individually assign a custom voice applications policy to users, you can use the Teams admin center or the Grant-CsTeamsVoiceApplicationsPolicy cmdlet.

In addition to creating and assigning a voice applications policy to users, a user must also be assigned as an authorized user to at least one auto attendant or call queue.voice application.

A user must be an authorized user to at least one auto attendant or call queue,voice application, and must have a voice applications policy assigned, to perform the actions described in Voice applications policy settings.

To learn more about the different ways that you can assign policies to users, see Assign policies to your users in Teams.

Voice applications policy settings

Voice applications policies control the configuration changes and actions an authorized user can make to the auto attendants and call queuesvoice applications they're authorized for. In addition, they also control which real-time and historical reports authorized users have access to. The following settings are available:

Auto attendants - Features

Reporting values:

  • None - no access to any metrics.
  • AuthorizedOnly - the authorized user only sees metrics for the auto attendants, call queues,voice applications and associated representatives (agents) they're authorized for.
  • All - the authorized user sees metrics for all auto attendants, call queues,voice applications and representatives.

Important

  1. The authorized user requires a Teams Premium license and Queues App to access this functionality.
  2. Under Call answering, the call queue must have Conference mode enabled.
  3. Under Agent selection, the call queue must have Presence-based routing enabled.
  4. If the authorized user is also a member in the call queue, they must be opted out in order to monitor.

Call queues - Reporting

Reporting values:

  • None - no access to any metrics.
  • AuthorizedOnly - the authorized user only sees metrics for the auto attendants, call queues,voice applications and associated representatives they're authorized for.
  • All - the authorized user sees metrics for all auto attendants, call queues,voice applications and associated representatives configured in the tenant.
