Prepare Network

13 November 2026Feature updateAction required+2 / −1 lines

In brief

The network preparation guidance now states that Teams clients, including in some VDI environments, might send media to UDP ports 49152–53247. Blocking these ports can cause media setup failures.

What Teams admins need to know

Review firewall rules and allow the specified UDP traffic from Teams clients where required.
